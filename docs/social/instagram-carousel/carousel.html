BELOW ACPI05—10

The missing trigger was a polling loop.

ACPI wrote shared memory and returned. We extracted the exact BIOS and ENE controller firmware to find who consumed it.

WMBH / FN20

Dynamic record

Mode, speed, brightness, direction, RGB.

PECM / F417—F41E

Shared memory

Host-visible bytes become controller input.

ENE 8051

Change detection

Mode, direction and enable bit compared against cache.

SMI D0 / F41F

Zone gates

Four bits independently enable four keyboard zones.

The ghost in the machine was watching memory.
